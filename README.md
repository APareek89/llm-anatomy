# Qwen anatomy

An interactive learning lab for Qwen/Qwen3.8-27B. Under construction in eight verified phases. Source metadata and downloaded weights are real; live calculations run in a separately labelled Micro-Qwen model.

## Run

Node 20.19+ is required. Run `npm install`, `npm run dev`. Run `npm test` and `npm run build` for validation.
